# Data: synthetic demonstration and observational benchmark

The committed panel is **synthetic**, generated by `src/synthetic.py` with seed
42. It contains 58 named California counties × 48 months (2022–2025), for 2,784
rows. Outcomes, environmental measurements, county effects, coordinates, and
identifiers are simulated. Coordinates and FIPS-like values are placeholders;
they are not valid geographic reference data.

`data/processed/panel.parquet` and the pickle fallback contain the demonstration
panel. Use notebook 01 to regenerate it. Prefer the parquet file; only load
pickle files from a trusted source.

## Observational workflow

`src/real_data.py` downloads or ingests source files, applies product quality
masks, aggregates rasters to actual California county boundaries, and builds a
county-month panel. `src/real_models.py` evaluates matched baseline and full
feature sets. The synthetic notebooks remain separate and use
`USE_SYNTHETIC = True`.

| Input | Implemented product |
| --- | --- |
| APHIS wild-bird detections | Explicit H5N1 and inclusive-H5 county-month report counts, with a source-quality audit |
| Terra MODIS MOD14A1.061 | Monthly nominal/high-confidence fire-pixel days and summed maximum fire radiative power |
| Terra MODIS MOD13A1.061 | QA-filtered county mean NDVI from 500 m, 16-day composites |
| Terra MODIS MOD11A2.061 | QA-filtered county mean daytime land-surface temperature from 1 km, 8-day composites |
| PRISM 4 km monthly data | Area-weighted county mean temperature and precipitation |
| USDA CDL 2021 cultivated layer | Cultivated fraction for all 58 counties |
| Census TIGER/Line 2024 counties | Geographic keys and polygon boundaries |

The committed summaries cover model inputs from December 2021 through June
2025 and outcomes through July 2025. A public MODIS cloud-mirror gap leaves
October 2022 NDVI unavailable; it remains missing and is imputed within each
training fold with a missingness indicator. Later 2025 MODIS gaps are why the
analysis endpoint is July rather than December. See
[`processed/real/README.md`](processed/real/README.md) and the machine-readable
coverage audit for details.

## Available observed SNPP VIIRS detections

The [July–October 2025 dataset](processed/viirs_snpp_375m_202507_202510/README.md)
contains four monthly point CSVs with 28,824 fire detections extracted from
707 science-quality VNP14IMG.002 granules. The dataset folder includes a
source manifest with SHA-256 checksums, daily catalog coverage, and validation
results. The source NetCDF archive is 1.33 GB and is stored locally under
`data/raw/viirs_snpp_375m_202507_202510/`.

To reproduce the download with Python 3.11 or newer, run from the repository root:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-viirs.txt
python scripts/download_viirs_snpp.py
```

Enter your Earthdata credentials at the interactive terminal prompts. The
script uses `persist=False`, reuses valid downloads, retries failed transfers,
and writes the monthly extracts to `data/raw/firms_viirs_ca_YYYYMM.csv`.
The committed copies under `data/processed/viirs_snpp_375m_202507_202510/`
are byte-identical to those extracts. The files are derived from NASA swaths;
the `firms_viirs_ca_` prefix matches the existing local CSV loader.

The bounding box is `(-124.6, 32.4, -113.9, 42.1)` in west/south/east/north
order. It includes places outside California. July 5–7, 2025 has no matching
source swaths; missing observations must not be filled as zero fire activity.
See the dataset README for field definitions and temporal precision.

## Observational panel assembly

1. Validate source schemas, coverage, dates, and surveillance definitions.
2. Aggregate the detection outcome and environmental measurements to compatible county-month keys.
3. Complete quality-masked raster extraction and document anomaly reference periods.
4. Join against a complete county-month grid; distinguish unobserved surveillance from confirmed zero detections.
5. Construct within-county disturbance lags using a defined prior observation window.
6. Apply geographic and temporal validation, matched feature comparisons, and dependence-aware uncertainty checks.

These steps are implemented in `src/real_data.py`; the original notebooks still
demonstrate the synthetic workflow. `data/raw/` is Git-ignored so source rasters,
the APHIS source export, and credentials are not published.
